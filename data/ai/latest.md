## 1. 🧠 AI Research Papers
### [RaReCache: Bridging the Gap in Cross-Model KV Cache Reuse via Rank Disagreement-Based Selective Recomputation (arXiv:2610.11358)](https://arxiv.org/abs/2610.11358)
- **Authors / Organization**: High-Performance Inference Systems Lab
- **Release Date**: October 9–10, 2026
- **Summary**: In high-concurrency LLM serving, prefill operations for large models (e.g. 70B) choke GPU compute and cause latency spikes. RaReCache enables a large target model to decode accurately from a KV cache prefilled by a much smaller source model (e.g., Qwen3-0.6B to 14B, or Llama-3-8B to 70B). It introduces an energy-based rank disagreement metric to detect which token positions suffered representation drift, recomputing only 30%–40% of the positions to retain 95%–99% of target accuracy while achieving up to 3.04x prefill speedup and reducing 99th-percentile TTFT by 6.4x.
- **Why it Matters**: Eliminates the need for massive models to compute the entire prefill phase, establishing an asynchronous "small-model prefill, large-model decode" architecture.
- **Practical Takeaway**: In multi-tier LLM infrastructure, disaggregate the prefill phase onto low-cost small-model nodes and selectively recompute drift tokens on the target node.
- **Key Concept / Benchmark**: Cross-Model KV Cache Reuse, Rank Disagreement Scoring, TTFT Saturation Benchmarks.

### [ResidualQuant: KV Cache Quantization for Looped Transformers with 2-Bit Residuals (arXiv:2610.10381)](https://arxiv.org/abs/2610.10381)
- **Authors / Organization**: Efficient Deep Learning Group
- **Release Date**: October 2026
- **Summary**: Looped transformers multiply KV cache memory traffic by repeating layer passes. ResidualQuant leverages the observation that KV states across recurrent loops are highly correlated, storing the final loop in high precision and representing intermediate loops with INT2 residuals using least-squares scaling and rotation transforms. Reduces KV cache memory footprint by 80.7% and improves peak serving throughput by 4.15x on consumer GPUs (RTX 5090) without degrading mathematical reasoning performance.
- **Why it Matters**: Demonstrates how residual encoding allows extreme sub-4-bit quantization without the catastrophic perplexity loss typical of naive uniform quantizers.
- **Practical Takeaway**: When quantizing recurrent or iterative reasoning representations, quantize the delta/residual against a reference state rather than raw activation tensors.
- **Key Concept / Benchmark**: Residual Quantization, Looped Transformers, INT2 Mixed Precision.

### [Bridging KV-Cache Quantization and Linear Attention (RAM-Net) (arXiv:2610.11214)](https://arxiv.org/abs/2610.11214)
- **Authors / Organization**: Scalable Attention Mechanisms Lab
- **Release Date**: October 2026
- **Summary**: Bridges the architectural gap between per-KV discrete quantization (which preserves all tokens) and linear recurrent attention (which compresses history into a fixed state but introduces interference). Introduces RAM-Net, which uses soft address assignments over discrete memory slots to locally approximate full-attention similarity while enabling recurrent constant-memory updates. Across nine pretrained Transformer models (0.3B–7B), enables direct weight migration from Transformers to RAM-Net with only 500M tokens of training.
- **Why it Matters**: Offers a mathematical bridge for converting quadratic attention Transformer checkpoints into linear-time constant-memory RNN-style engines.
- **Practical Takeaway**: Linear attention and quantized KV caching are mathematically duals; soft addressing bridges the gap for sub-quadratic inference.
- **Key Concept / Benchmark**: RAM-Net, Soft Address Assignments, Transformer-to-RNN Weight Migration.

## 6. 📚 Concept of the Day: Cross-Model KV Cache Reuse & Rank Disagreement
### Simple Explanation (Beginner): Instead of having an expensive senior editor read...
- **Simple Explanation (Beginner)**: Instead of having an expensive senior editor read a 500-page book from scratch, a fast intern reads it first and writes detailed notes (the KV cache). The senior editor quickly double-checks the 30% most difficult pages and writes the final chapter. Small models do the heavy reading, while large models do the deep thinking.
- **Technical Explanation (Intermediate)**: In standard LLM inference, prefill is compute-bound ($O(N^2)$), while decode is memory-bandwidth bound ($O(1)$ per token). RaReCache lets a small source model compute prompt KV tensors, maps them via learned linear projections to the target model's hidden dimension, computes an energy-based rank disagreement metric to detect token drift, and recomputes only the top 30%–40% critical positions on the target model. This retains 95%–99% accuracy while cutting TTFT by up to 6.4x.
- **Practical Takeaway**: In multi-tier LLM infrastructure, disaggregate the prefill phase onto low-cost small-model nodes and selectively recompute drift tokens on the target node.
